Linear Equations in One Variable

  • Algebra
  • Linear equations in one variable
All Math lessonsNext→

A linear equation in one variable has a single unknown, and solving it means undoing the operations around that unknown. Decide first what the question wants: the variable, an expression built from it, a constant, or what a letter in a model stands for.

Key takeaways

  • Add or subtract the same expression on both sides; multiply or divide by a nonzero number.
  • Simplify first: distribute, clear fractions, and combine like terms.
  • Put the variable terms on one side and the constants on the other.
  • Divide by the coefficient of the variable, its sign included.
  • If the variable cancels: a false statement means no solution, a true one means infinitely many.
  • Answer the quantity the question asks for, which is not always xxx.

What the SAT may ask

  • Solve an equation for its variable.
  • Solve, then report an expression such as 7x+27x + 27x+2.
  • Find a constant when one solution is given.
  • Find the constant that gives an equation no solution, or infinitely many.
  • Write an equation from a story and solve it.
  • Say which quantity a letter or a number in a model stands for.

The rule

An equation is a claim that two expressions are equal. Adding or subtracting the same expression on both sides, and multiplying or dividing both sides by the same nonzero number, leave the solutions unchanged. You may also rewrite either side on its own as an equal expression.

Solve by undoing the operations in reverse order: clear, then collect, then divide by the coefficient of the variable, its sign included.

4x+9=414x + 9 = 414x+9=41 4x=324x = 324x=32 x=8x = 8x=8

When a grouping stands alone on one side and the other side is a single number, divide both sides by the multiplier rather than distributing. When the question asks for the grouping itself, that one division answers it and there is no need to find xxx.

5(3x−2)=405(3x - 2) = 405(3x−2)=40 3x−2=83x - 2 = 83x−2=8

Why the rule exists

4x+94x + 94x+9 was built in an order: multiply by 444, then add 999. Taking it apart runs the other way, so the 999 goes first and the division goes last.

Rewriting one side is not the same as changing it. Distributing, or combining like terms, replaces a side with an expression equal to it, so the equation is untouched. Adding a number, or multiplying by a number, has to reach both sides.

The sign travels with the coefficient. In −2x=14-2x = 14−2x=14 the coefficient is −2-2−2, so divide by −2-2−2. Dividing by 222 leaves −x=7-x = 7−x=7, and reading that as x=7x = 7x=7 drops the minus that is still there. The solution is −7-7−7.

Worked examples

1. Keep a negative coefficient

Solve 14−3x=2914 - 3x = 2914−3x=29.

Question asks: the value of xxx.

First move: subtract 141414 from both sides.

−3x=15-3x = 15−3x=15

Divide both sides by −3-3−3, coefficient and sign together.

x=−5x = -5x=−5

Answer: −5-5−5

Common mistake: reading the coefficient as 333 rather than −3-3−3, which gives 555, the right digit with the wrong sign. Dividing by 333 is legal on its own: it leaves −x=5-x = 5−x=5, and the sign is lost only if that last step is skipped.

2. Clear the decimals, then collect

Solve 0.4x+1.5=0.1x+30.4x + 1.5 = 0.1x + 30.4x+1.5=0.1x+3.

Question asks: the value of xxx.

First move: multiply every term on both sides by 101010.

4x+15=x+304x + 15 = x + 304x+15=x+30

Subtract xxx from both sides.

3x+15=303x + 15 = 303x+15=30

Subtract 151515 from both sides.

3x=153x = 153x=15

Divide both sides by 333.

x=5x = 5x=5

Answer: 555

Common mistake: multiplying only the left side by 101010 leaves 4x+154x + 154x+15 facing 0.1x+30.1x + 30.1x+3, and every step after that solves a different equation.

3. Write the equation from the story

The length of a rectangle is 555 cm more than twice its width, and its perimeter is 464646 cm. What is the width of the rectangle?

Question asks: the width, in centimeters.

First move: call the width www, so the length is 2w+52w + 52w+5, and a perimeter is two widths plus two lengths.

2w+2(2w+5)=462w + 2(2w + 5) = 462w+2(2w+5)=46

Distribute the 222 across both terms inside the grouping.

2w+4w+10=462w + 4w + 10 = 462w+4w+10=46

Combine the like terms.

6w+10=466w + 10 = 466w+10=46

Subtract 101010 from both sides.

6w=366w = 366w=36

Divide both sides by 666.

w=6w = 6w=6

Answer: 666 cm

Check: you wrote this equation yourself, so put the width back into the story. The length is 2(6)+52(6) + 52(6)+5, which is 171717, and the four sides 666, 171717, 666 and 171717 give 464646.

4. When the variable cancels

In the equation 4(2x+3)=8x+k4(2x + 3) = 8x + k4(2x+3)=8x+k, kkk is a constant. If the equation has infinitely many solutions, what is the value of kkk?

Question asks: the constant kkk. There is no single xxx to find, because infinitely many solutions means every xxx works.

First move: distribute the 444 on the left.

8x+12=8x+k8x + 12 = 8x + k8x+12=8x+k

Subtract 8x8x8x from both sides, and the variable is gone.

12=k12 = k12=k

Answer: 121212

Check: kkk is a constant you solved for, so put it back. Both sides then read 8x+128x + 128x+12, which is true whatever xxx is.

Special cases

One solution, none, or infinitely many

Simplify both sides until the equation reads ax+b=cx+dax + b = cx + dax+b=cx+d. The coefficients decide whether there is one solution. When they match, the constants decide between none and infinitely many.

What you see The outcome
aaa and ccc differ One solution
a=ca = ca=c, and bbb and ddd differ The variable cancels and leaves a false statement, such as 0=110 = 110=11. No solution
a=ca = ca=c and b=db = db=d The two sides are one expression written twice. Infinitely many solutions

A question can make one of those four letters the unknown instead. The variable is still xxx, and the letter you solve for is a coefficient or a constant term.

Read which of the three rows the question names, then work back to the letter. No solution and infinitely many both need the two coefficients to match, so make them match first, and let the constants tell you which of the two you have. Where the coefficients already match whatever the letter is, the constants decide alone.

A question that states a solution rather than a count is a different job: substitute it and solve for the letter.

Common traps

The ask, the sign, and the half-cleared equation

Trap Quick check
Answering xxx when the ask was an expression Re-read what you wrote in step 1
Dropping the minus while dividing by a coefficient The sign is part of the coefficient
Multiplying one side by the common denominator Every term, on both sides

The method: Target, simplify, isolate, answer

  1. Identify the target. Write down what the question wants: xxx, an expression built from xxx such as 7x+27x + 27x+2, a constant, or what a letter in a model stands for. In a story that names no variable, choose one first.
  2. Simplify. In a story with no equation yet, write the one the sentences describe. Substitute any value you were given. Distribute across groupings, innermost first, multiplying every term inside. When a grouping stands alone against a number, divide both sides by its multiplier. Clear fractions and decimals, every term on both sides. Combine like terms, and only like terms.
  3. Isolate the unknown. When a number is wanted, collect the variable terms on one side and the constants on the other. Then divide by the coefficient of the letter you are solving for, sign included. When a constant is wanted, either substitute a solution the question states, or make the variable cancel and solve what is left.
  4. Classify or answer. If the variable cancels and no constant is asked for, read what is left: a false statement means no solution, a true one means every number works. Otherwise give the quantity from step 1, substituting back when you wrote the equation yourself from a story, or when the value you found is a constant.

When the built-in calculator helps

A graphing calculator is built into the testing app and is allowed on every Math question.

Graph the left side and the right side as two lines. They cross at the solution. That is worth doing when the numbers are awkward, when the answer is not a whole number, or when you want to check one you already have.

The same picture settles the special cases. Two parallel lines mean no solution, and one line drawn twice means every number works.

A two-step equation is faster by hand. So is an equation with two letters in it, until a value you are given leaves one.

Practice

Work each item with the method, under a rough clock: about a minute for a bare equation, and up to about two minutes once there is a context to translate or a graph or table to read first. The Math section gives you about 95 seconds a question on average, so that range is test-day pace rather than a drill speed. Press Show solution to see the steps, one to a line.

If 4x+2x+6=304x + 2x + 6 = 304x+2x+6=30, what is the value of xxx?

Correct. Combining the like terms and undoing in order gives x=4x = 4x=4.

The method, applied

Step 1. The target is xxx.

Step 2. Nothing to distribute or clear, but 4x4x4x and 2x2x2x are like terms, so combine them. The 666 is not a multiple of xxx and stays where it is.

6x+6=306x + 6 = 306x+6=30

Step 3. Subtract 666 from both sides.

6x=246x = 246x=24

Divide both sides by 666.

x=4x = 4x=4

Step 4. The answer is 444.

Correct. 434343 is dollars for each hour and 43h43h43h is dollars, so hhh is a number of hours.

Steps 2 and 3. The equation is already written and the question asks for no number, so there is nothing to simplify and nothing to isolate.

If 2[3(x−1)+4]=5x+72[3(x - 1) + 4] = 5x + 72[3(x−1)+4]=5x+7, what is the value of 4x−14x - 14x−1?

Correct. Working the groupings from the inside out gives x=5x = 5x=5, and the target, 4x−14x - 14x−1, is then 191919.

The method, applied

Step 1. The target is 4x−14x - 14x−1, not xxx. Write it down before starting.

Step 2. Work from the inside out. Distribute the 333 across the inner grouping.

2[3x−3+4]=5x+72[3x - 3 + 4] = 5x + 72[3x−3+4]=5x+7

Combine the constants inside the brackets.

2(3x+1)=5x+72(3x + 1) = 5x + 72(3x+1)=5x+7

Distribute the 222 across both of its terms.

6x+2=5x+76x + 2 = 5x + 76x+2=5x+7

Step 3. Subtract 5x5x5x from both sides.

x+2=7x + 2 = 7x+2=7

Subtract 222 from both sides.

x=5x = 5x=5

Step 4. The target was 4x−14x - 14x−1.

4(5)−1=194(5) - 1 = 194(5)−1=19

The answer is 191919.
