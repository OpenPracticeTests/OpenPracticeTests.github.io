Linear Functions

  • Algebra
  • Linear functions
←PreviousAll Math lessonsNext→

A linear function turns an input into an output by adding the same amount for every step the input takes. Decide first what the question wants: an output, an input, the rate of change, or the starting value.

Key takeaways

  • In f(x)=mx+bf(x) = mx + bf(x)=mx+b, mmm is the rate of change and bbb is the output at an input of zero.
  • The rate of change is the change in output divided by the change in input.
  • f(a)f(a)f(a) is an output. Solving f(x)=cf(x) = cf(x)=c gives an input.
  • On a graph, move vertically from an input and horizontally from an output.
  • Over a gap of hhh in the input, the output changes by m×hm \times hm×h.
  • A relationship is linear only if equal steps in the input give equal steps in the output.

What the SAT may ask

  • Find an output from a rule, a table, or a graph.
  • Find the input that produces a stated output.
  • Find the rate of change from a table or a graph.
  • Find the output when the input is zero.
  • Say what a rate of change or a starting value means in a described situation.
  • Decide whether a table could come from a linear function.

The rule

A linear function is written f(x)=mx+bf(x) = mx + bf(x)=mx+b. The letter fff is the function's name, xxx is the input, and f(x)f(x)f(x) is the output that input produces. So f(3)f(3)f(3) is not a multiplication: it is the output when the input is 333.

mmm is the rate of change, the amount the output moves for each increase of one in the input. bbb is the starting value, the output when the input is zero, because substituting zero removes the mxmxmx term.

Both readings need the rule written as f(x)=mx+bf(x) = mx + bf(x)=mx+b first.

f(t)=50+6(t−2)f(t) = 50 + 6(t - 2)f(t)=50+6(t−2)

The rate here is 666, and the 505050 is the output at an input of 222 rather than at zero. Multiplying out shows the starting value.

f(t)=6t+38f(t) = 6t + 38f(t)=6t+38

The rate of change is a division. Take the change in output and divide it by the change in input. If f(2)=11f(2) = 11f(2)=11 and f(6)=27f(6) = 27f(6)=27, the output rose by 161616 across a gap of 444.

m=164m = \frac{16}{4}m=416​ m=4m = 4m=4

Once the rate is known, one output gives the starting value. Substitute f(2)=11f(2) = 11f(2)=11 into f(x)=4x+bf(x) = 4x + bf(x)=4x+b.

11=4(2)+b11 = 4(2) + b11=4(2)+b b=3b = 3b=3

A graph is read in two directions, and the ask decides which. For an output, move vertically from the input on the horizontal axis to the graph, then horizontally to the vertical axis. The vertical move goes down when the output is negative.

For an input, run that path backwards, starting on the vertical axis.

Over a gap in the input, the output changes by the rate times that gap, so across a gap of hhh the change is m×hm \times hm×h. The starting value plays no part, because it is added at both ends and cancels.

In a described situation, the rate and the starting value both carry units. If a function gives a temperature in degrees after ttt minutes, the rate is degrees per minute and the starting value is degrees.

The situation also decides which inputs mean anything. A count of items is a whole number, elapsed time is not negative, and a stated interval bounds the rest. An input the algebra accepts can still be one the story has no room for.

Why the rule exists

A rate compares two changes, so it has to be a division. A rise of 161616 means nothing until you say what it rose across. Over a gap of 444 it is 444 per unit; over a gap of 888 it is 222.

The output is built from repeated addition, which is why the same rate works everywhere along the function. Adding mmm once for each of hhh steps adds m×hm \times hm×h in total.

Worked examples

1. Write the function when the rate covers several units

A cart already holds 181818 sacks when loading starts, and a loader adds 242424 more sacks every 444 hours. Write a function SSS giving the number of sacks on the cart hhh hours after loading starts, and say what each number in it means.

Question asks: the rule, and the meaning of its two numbers.

First move: turn the rate into an amount per one hour.

The loader adds 242424 sacks across 444 hours, so divide.

m=244m = \frac{24}{4}m=424​ m=6m = 6m=6

The cart already holds 181818 sacks when hhh is zero, so that is the starting value.

S(h)=6h+18S(h) = 6h + 18S(h)=6h+18

Answer: S(h)=6h+18S(h) = 6h + 18S(h)=6h+18

The 666 is sacks per hour, the rate the load grows at. The 181818 is sacks, the number on the cart before loading started.

Check: you built this rule, so substitute a value the question states. After 444 hours the cart should hold the original 181818 sacks plus the 242424 the loader adds.

S(4)=6(4)+18S(4) = 6(4) + 18S(4)=6(4)+18 S(4)=42S(4) = 42S(4)=42

Common mistake: writing S(h)=24h+18S(h) = 24h + 18S(h)=24h+18 treats 242424 sacks every four hours as 242424 sacks every hour, which is four times the real rate.

2. Decide whether a table shows a linear function

Which of these tables could be generated by a linear function?

x p(x)
3 17
7 33
12 53
15 65
x q(x)
0 4
1 7
2 12
3 19

Question asks: which table has one rate of change.

First move: divide each change in output by its own change in input, keeping one row back for the check. The rows of the first table are not evenly spaced, so the differences alone say nothing.

Between the first two rows the output rises by 161616 across a gap of 444.

164=4\frac{16}{4} = 4416​=4

Between the second and third rows it rises by 202020 across a gap of 555.

205=4\frac{20}{5} = 4520​=4

The second table steps by one every time, so its differences are its rates: 333, then 555, then 777. They are not equal, so no single rate describes qqq.

Answer: the first table.

Check: you built a rate, so test it on the row you did not use. Stepping back three units from the first row drops the output by 121212, which puts the starting value at 555.

p(x)=4x+5p(x) = 4x + 5p(x)=4x+5

At an input of 151515 that gives 656565, which is the last row the table prints.

Four rows can rule a function out, as the second table's do. They cannot prove the first table's rule holds between them or past them. The rows are consistent with one rate, which is the most a finite table says.

3. The change across a gap does not depend on where the gap starts

The function fff is defined by f(x)=9x−4f(x) = 9x - 4f(x)=9x−4. What is f(a+4)−f(a)f(a + 4) - f(a)f(a+4)−f(a)?

Question asks: the change in output across a gap of 444, from any starting input.

First move: write out each output separately.

f(a+4)=9(a+4)−4f(a + 4) = 9(a + 4) - 4f(a+4)=9(a+4)−4 f(a+4)=9a+36−4f(a + 4) = 9a + 36 - 4f(a+4)=9a+36−4 f(a+4)=9a+32f(a + 4) = 9a + 32f(a+4)=9a+32 f(a)=9a−4f(a) = 9a - 4f(a)=9a−4

Subtract the second from the first. The 9a9a9a terms cancel, and 323232 less −4-4−4 is 363636.

(9a+32)−(9a−4)=36(9a + 32) - (9a - 4) = 36(9a+32)−(9a−4)=36

Answer: 363636

The letter aaa has disappeared, which is the point: the change is 9×49 \times 49×4 wherever the gap sits. That is the rate times the width of the gap, and it is the same fact the rule block states.

Special cases

A rate of zero, and a rate below zero

When mmm is negative the output falls as the input rises. The graph in the rule block is such a function: its rate is −2-2−2, so every step right drops it two.

When mmm is zero the rule reads f(x)=bf(x) = bf(x)=b. Every input gives the same output, the graph is a horizontal line, and the function is still linear.

A vertical line is not a function at all, because one input would have to give several outputs. Lines as lines, and the forms an equation of a line can take, belong to Linear Equations in Two Variables.

Common traps

Rate, starting value, and the gap between two inputs

A change in output becomes a rate only after it is divided by the change in input. That division is invisible whenever the inputs happen to be one apart.

Trap Quick check
Reading a change in output as the rate Divide by the change in the input, which is not always 111
Reading the starting value as the rate, or the reverse Multiply out to f(x)=mx+bf(x) = mx + bf(x)=mx+b; then mmm sits on the xxx and bbb stands alone
Tracing a graph from the wrong axis An input sits on the horizontal axis, an output on the vertical
Multiplying the rate by an input instead of by a gap A change across an interval is the rate times the width of that interval

The method: Ask, read, build, answer

  1. Name the ask. An output, an input, the rate of change, the starting value, a change across an interval, or a comparison between two functions. Write down which one you want before you touch the numbers.
  2. Read what you were given. In an equation, multiply out to f(x)=mx+bf(x) = mx + bf(x)=mx+b: the rate multiplies the input, the starting value stands alone. In a table, divide each change in output by its own change in input. On a graph, use two points the grid marks exactly. In words, the per-unit amount is the rate.
  3. Build f(x)=mx+bf(x) = mx + bf(x)=mx+b, or use the one you were handed. Substitute an input to get an output. Set the rule equal to an output to get an input. Multiply the rate by a gap to get a change across that gap.
  4. Answer the ask. If you built the rule or the rate yourself, check it first by substituting a row, a point, or a stated value back into it. When it was handed to you whole, check the answer against the ask: its units, or its identity where there are none. Give the quantity the ask names, with its units when it has any.

Let a graph find the input

A graphing calculator is built into the testing app and is allowed on every Math question.

Graph y=f(x)y = f(x)y=f(x) and the horizontal line y=cy = cy=c together. The xxx-value where they cross is the input whose output is ccc.

A table of values shows a rate directly: step the input by one and read how much the output moves.

When the rule is already written down, substituting one number is quicker than typing the function in.

The table gives four values of xxx and the corresponding values of f(x)f(x)f(x) for a linear function fff.

x f(x)

What is the rate of change of fff?

Correct. The output rises by 121212 across a gap of 444, and 121212 divided by 444 is 333.

The method, applied

Step 1. The ask is the rate of change, which is the amount the output moves for each increase of one in the input.

Step 2. The table gives rows rather than a rule, so divide a change in output by its own change in input. Across the first two rows the output goes from 666 to 181818 while the input goes from 000 to 444.

m=18−64−0m = \frac{18 - 6}{4 - 0}m=4−018−6​ m=3m = 3m=3

Step 3. Nothing further has to be built, since the ask is the rate itself.

Step 4. You built this rate, so test it on rows you did not use. Across the last two rows the output rises by 121212 over a gap of 444, which is the same 333 per unit. The answer is 333.

Correct. Substituting 555 gives 6(5)−116(5) - 116(5)−11, which is 191919.

The method, applied

Step 1. The ask is which pair satisfies the rule, so each candidate's first number is an input and its second is the output that input must produce.

Step 2. The rule is handed over, so the rate is 666 and the starting value is −11-11−11. Nothing has to be built.

Step 3. Substitute the first coordinate and see whether the second one comes out. At an input of 555:

f(5)=6(5)−11f(5) = 6(5) - 11f(5)=6(5)−11 f(5)=19f(5) = 19f(5)=19

Machine A has produced 606060 parts when a shift starts and produces 242424 more each hour. Machine B is modeled by B(h)=32h+12B(h) = 32h + 12B(h)=32h+12, where B(h)B(h)B(h) is the number of parts machine B has produced hhh hours after the shift starts. After 222 hours, how many parts has machine A produced beyond machine B's total?

Correct. After two hours machine A has 108108108 parts and machine B has 767676, a gap of 323232.

The method, applied

Step 1. The ask is the gap between two outputs at one stated input.

Step 2. Machine A is described in words, so build its rule: the rate is 242424 parts per hour and the starting value is 606060 parts. Machine B is handed over, with a rate of 323232 and a starting value of 121212.

A(h)=24h+60A(h) = 24h + 60A(h)=24h+60

Step 3. Substitute 222 into each.

A(2)=24(2)+60A(2) = 24(2) + 60A(2)=24(2)+60 A(2)=108A(2) = 108A(2)=108 B(2)=32(2)+12B(2) = 32(2) + 12B(2)=32(2)+12 B(2)=76B(2) = 76B(2)=76

Now take A's total less B's total.

108−76=32108 - 76 = 32108−76=32

Step 4. You built machine A's rule, so substitute the value the stem states back into it: at zero hours it gives 606060 parts, which is what the shift starts with. The answer is 323232 parts.

A freight train's total distance from its depot, in kilometers, is modeled by D(t)=28t+15D(t) = 28t + 15D(t)=28t+15, where ttt is the number of hours since the train passed a signal box 151515 kilometers out. How much farther from the depot is the train at 555 hours than at 222 hours?

Correct. The rate is 282828 kilometers per hour across an interval three hours wide, so 28(3)28(3)28(3) is 848484.

The method, applied

Step 1. The ask is a change across an interval, not a distance at one time.

Step 2. The rule is handed over. The rate is 282828 kilometers per hour and the starting value is the 151515 kilometers already behind the train at the signal box.

Step 3. A change across an interval is the rate times the width of that interval, and the interval from 222 hours to 555 hours is three hours wide.

28×3=8428 \times 3 = 8428×3=84

Step 4. Check the units: kilometers per hour times hours is kilometers, which is what the question asks for. The answer is 848484 kilometers.
