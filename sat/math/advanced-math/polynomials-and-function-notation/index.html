Polynomials and Function Notation

  • Advanced Math
  • Nonlinear functions
←PreviousAll Math lessonsNext→

Function notation is a set of instructions: f(a)f(a)f(a) means put aaa into the rule called fff. Decide first whether the question wants an output, an input, a factor, a remainder, or the shape of the graph.

Key takeaways

  • f(a)f(a)f(a) means put aaa wherever xxx stands in the rule for fff.
  • In f(g(x))f(g(x))f(g(x)), work from the inside out: ggg first, then fff.
  • A real zero ccc, the factor x−cx - cx−c, and the xxx-intercept (c,0)(c, 0)(c,0) are one fact in three forms.
  • Dividing p(x)p(x)p(x) by x−cx - cx−c leaves a remainder of p(c)p(c)p(c), so x−cx - cx−c is a factor exactly when p(c)=0p(c) = 0p(c)=0.
  • Write a divisor as x−cx - cx−c before reading ccc, because x+5x + 5x+5 has c=−5c = -5c=−5.
  • The leading term decides both far ends of the graph, so put the polynomial in descending order first.
  • A change inside the parentheses moves the input, and a change outside moves the output.

What the SAT may ask

  • Evaluate a function at a number, at an expression, or inside another function.
  • Read an output or an input off a table or a graph of a function.
  • Find a remainder, decide whether a linear expression is a factor, or find a constant that makes it one.
  • Report the zeros or the xxx-intercepts of a polynomial given in factored form.
  • Describe the far ends of a polynomial's graph, or the graph after a shift or a reflection.
  • Match a rational function's graph to its equation using the asymptotes.

The rule

A function is a rule with one output for each input, and f(a)f(a)f(a) is the output when the input is aaa. To evaluate it, put aaa wherever xxx stands. For f(x)=x2−11f(x) = x^2 - 11f(x)=x2−11:

f(−4)=(−4)2−11f(-4) = (-4)^2 - 11f(−4)=(−4)2−11 f(−4)=5f(-4) = 5f(−4)=5

The input can be an expression rather than a number. For the same rule, f(a+1)f(a + 1)f(a+1) is (a+1)2−11(a + 1)^2 - 11(a+1)2−11. A polynomial is a sum of terms whose exponents are whole numbers.

In f(g(x))f(g(x))f(g(x)), the output of ggg is the input of fff. Work from the inside out, and keep the order: never assume f(g(x))f(g(x))f(g(x)) and g(f(x))g(f(x))g(f(x)) are the same rule. A composition inherits both domains: it allows only the inputs ggg allows that also keep fff defined.

A zero of ppp is an input ccc with p(c)=0p(c) = 0p(c)=0. Three statements say the same thing:

The graph beside this rule crosses at −3-3−3, −1-1−1 and 222, so x+3x + 3x+3, x+1x + 1x+1 and x−2x - 2x−2 are all factors of it.

Dividing p(x)p(x)p(x) by x−cx - cx−c leaves a remainder of p(c)p(c)p(c), so one substitution gives it, and a remainder of 000 means x−cx - cx−c is a factor.

The leading term decides both far ends of the graph. Write the polynomial in descending order first.

An even degree sends both ends the same way and an odd degree sends them opposite ways. Above degree zero, a positive leading coefficient rises on the right and a negative one falls.

A change inside the parentheses moves the input; a change outside moves the output. For a positive kkk and a positive aaa:

Put the two shifts together as f(x−h)+kf(x - h) + kf(x−h)+k: the point (p,q)(p, q)(p,q) on the graph of fff moves to (p+h,q+k)(p + h, q + k)(p+h,q+k).

A rational function g(x)=ax−h+kg(x) = \frac{a}{x - h} + kg(x)=x−ha​+k, with aaa not zero, is ax\frac{a}{x}xa​ moved the same way. The input hhh is excluded, because it makes the denominator zero. When the numerator cancels a denominator factor away entirely, that factor's real zeros become holes rather than asymptotes. Canceling turns (x−1)(x+4)x−1\frac{(x - 1)(x + 4)}{x - 1}x−1(x−1)(x+4)​ into x+4x + 4x+4, and 111 stays excluded, so the graph is that line with one point missing.

Why the rule exists

Dividing polynomials works like dividing whole numbers. Dividing p(x)p(x)p(x) by x−cx - cx−c gives a quotient q(x)q(x)q(x) and a remainder rrr that is only a number, because the divisor has degree 111.

p(x)=(x−c)q(x)+rp(x) = (x - c)q(x) + rp(x)=(x−c)q(x)+r

That holds for every xxx, so it holds at x=cx = cx=c. There the first term is 000 times q(c)q(c)q(c), which leaves p(c)=rp(c) = rp(c)=r.

The inside change looks backward because the parentheses hold the input, not the output. In f(x+4)f(x + 4)f(x+4), an xxx of 111 puts 555 into fff, so the new graph shows at 111 what the old graph showed at 555. The picture slides left.

The far ends belong to the leading term because powers grow at different speeds: once ∣x∣|x|∣x∣ is large enough, ∣x3∣|x^3|∣x3∣ beats any fixed multiple of x2x^2x2.

Worked examples

1. Evaluate a composition from a table

The table gives four values of the functions fff and ggg. What is the value of g(f(1))g(f(1))g(f(1))?

xxx f(x)f(x)f(x) g(x)g(x)g(x)
−1-1−1 444 000
111 333 −2-2−2
333 −1-1−1 555
444 111 666

Question asks: one output of ggg.

First move: work from the inside out, so find f(1)f(1)f(1) before touching ggg. Read across the row whose input is 111, in the column headed f(x)f(x)f(x).

f(1)=3f(1) = 3f(1)=3

That 333 is now the input to ggg. Read across the row whose input is 333, in the column headed g(x)g(x)g(x).

g(3)=5g(3) = 5g(3)=5

Answer: 555

Common mistake: running the two rules in the other order. The inside function is ggg there, and its output at 111 is −2-2−2, which is not an input the table lists at all. If the table has no row for the number you need, check the order first.

2. Test two divisors to find the factor

The polynomial ppp is defined by p(x)=x3+x2−14x−24p(x) = x^3 + x^2 - 14x - 24p(x)=x3+x2−14x−24. Which of x−4x - 4x−4 and x+4x + 4x+4 is a factor of p(x)p(x)p(x)?

Question asks: which of two divisors is a factor.

First move: set each divisor to zero to get the number to substitute. The divisor x−4x - 4x−4 is zero at 444, and x+4x + 4x+4 is zero at −4-4−4.

A factor leaves a remainder of 000, so work out p(4)p(4)p(4) first.

p(4)=64+16−56−24p(4) = 64 + 16 - 56 - 24p(4)=64+16−56−24 p(4)=0p(4) = 0p(4)=0

Now the other one.

p(−4)=−64+16+56−24p(-4) = -64 + 16 + 56 - 24p(−4)=−64+16+56−24 p(−4)=−16p(-4) = -16p(−4)=−16

Answer: x−4x - 4x−4

Nothing was solved for, so there is no number to put back. The second substitution is not wasted work: −16-16−16 is the remainder when p(x)p(x)p(x) is divided by x+4x + 4x+4.

Common mistake: substituting −4-4−4 for the divisor x−4x - 4x−4. Copying the constant with the sign it is written with reverses both tests at once.

3. Move a point through a change inside and a change outside

The graph of y=f(x)y = f(x)y=f(x) passes through the point (6,−2)(6, -2)(6,−2). The function ggg is defined by g(x)=f(x−3)+5g(x) = f(x - 3) + 5g(x)=f(x−3)+5. Which point must the graph of y=g(x)y = g(x)y=g(x) pass through?

Question asks: one point on the new graph.

First move: the only thing known about fff is its output at 666, so make the inside of the parentheses equal 666.

x−3=6x - 3 = 6x−3=6 x=9x = 9x=9

At that input the value inside the parentheses is 666, and the output of fff there is −2-2−2. The +5+5+5 sits outside, so it is added to that output.

g(9)=−2+5g(9) = -2 + 5g(9)=−2+5 g(9)=3g(9) = 3g(9)=3

Answer: (9,3)(9, 3)(9,3)

Check: you solved for a number, so put 999 back in. The inside becomes 9−39 - 39−3, which is the input the point was given at, and the outside adds 555 to the output −2-2−2.

Common mistake: taking 333 away from the given input instead of adding it. That lands at an input of 333, which is the inside change run the way it is written.

Special cases

When counting zeros and turns needs more care

Degree gives a ceiling, not a count. A polynomial of degree nnn has at most nnn real zeros.

A repeated factor gives one zero, not two. The graph of y=(x−5)2(x+2)y = (x - 5)^2(x + 2)y=(x−5)2(x+2) has degree 333 and two xxx-intercepts. An even number of repeats touches the axis and turns back; an odd number crosses, so (x−5)3(x+2)(x - 5)^3(x + 2)(x−5)3(x+2) crosses at 555.

A factor that is never zero gives none. A square is never negative, so x2+25x^2 + 25x2+25 is at least 252525, and a polynomial carrying that factor gets no xxx-intercept from it.

The turns have a ceiling too. A graph of degree nnn changes direction at most n−1n - 1n−1 times.

Common traps

The sign inside the parentheses

A constant inside parentheses reverses on the way out.

The method: Ask, read the form, work, answer

  1. Name the ask. An output, an input, a zero, a factor, a remainder, a constant inside the polynomial, the shape of the graph, or a new function. Write it down before you start, because the ask alone decides which move comes next.
  2. Read the form you were given. In f(g(x))f(g(x))f(g(x)), ggg runs first. A factored form displays the zeros, and a stated zero displays a factor. A change inside the parentheses acts on the input, outside on the output. Reorder the terms if they are not in descending order.
  3. Carry out the one move the ask names, one thing to a line. Substitute, read a value off a table or a graph, or work inside out. Set each factor to zero for the zeros, or work out p(c)p(c)p(c) for a remainder. Read the leading term for the far ends, or read hhh and kkk off a pair of asymptotes.
  4. Answer the ask, and check when you solved for a number. Put that number back into the function and confirm the value the question states. Skip the check when nothing can go back in. A table or graph reading, an expression, a factor, a chosen equation and a description of the graph are all of that kind.

Check a zero by graphing

A graphing calculator is built into the testing app and is allowed on every Math question.

Enter y=p(x)y = p(x)y=p(x) and look at where the curve meets the horizontal axis. Each xxx-intercept is a real zero, whether the curve crosses there or touches and turns, and the picture settles which way each far end goes.

A picture can rule a factor out, but a near miss and a hit look alike on screen, so settle it with p(c)p(c)p(c).

For a polynomial function ppp, the value of p(−13)p(-13)p(−13) is 000. Which of the following must be true?

Correct. A factor is written x−cx - cx−c and is zero at ccc, and here ccc is −13-13−13.

The method, applied

Step 1. The ask is which statement follows from one stated value, so nothing is evaluated.

Step 2. Read the form. Saying that p(−13)p(-13)p(−13) is 000 says that −13-13−13 is a zero of ppp, and a factor is written x−cx - cx−c and is zero at ccc.

Step 3. Put −13-13−13 in the place of ccc.

x−(−13)=x+13x - (-13) = x + 13x−(−13)=x+13

Step 4. Nothing was solved for, and the stem never prints a rule for ppp, so there is nothing to substitute into. The statement that must be true is that x+13x + 13x+13 is a factor of p(x)p(x)p(x).

Correct. The factor x−7x - 7x−7 is zero at 777, and the other factor is never zero.

The method, applied

Step 1. The ask is a point on the xxx-axis, so the output there is 000.

Step 2. The form is already factored, so the zeros come from setting each factor to zero rather than from multiplying anything out.

Step 3. Take the first factor.

Now the second one. A square is never negative, so x2+4x^2 + 4x2+4 is at least 444 for every real input and can never be zero. The graph crosses the axis once.
