Radical, Rational, and Absolute Value Equations

  • Advanced Math
  • Nonlinear equations in one variable and systems of equations in two variables
←PreviousAll Math lessonsNext→

In these equations the variable sits under a radical, inside an absolute value, in a denominator, or under a fractional exponent. Undo the operation that hides it, then decide whether every value that came out is really a solution.

Key takeaways

  • Get the radical, the absolute value, or the power alone before you undo it.
  • Undo a radical with its own index: square a square root, cube a cube root.
  • Squaring can create a value the original equation rejects. Cubing cannot.
  • A denominator is never zero, so write down its forbidden values before you clear it.
  • An absolute value equals a positive number in two ways, zero in one way, and a negative number in none.
  • Undo xm/nx^{m/n}xm/n by raising both sides to nm\frac{n}{m}mn​, which can drop a solution or invent one.
  • Test each candidate in the equation you were given, not in a later line.

What the SAT may ask

  • Solve an equation with the variable under a radical.
  • Solve an equation with the variable in a denominator.
  • Solve an equation with a fractional exponent.
  • Find a value that satisfies an absolute value equation.
  • Find a constant that leaves an equation with no solution.

The rule

Each equation here hides the variable inside one operation. Undo that operation, then test what comes out, because most of these routes can produce a number the original equation does not accept.

A radical. Get the radical alone, then raise both sides to its index: square a square root, cube a cube root.

x−1=6\sqrt{x - 1} = 6x−1​=6 x−1=36x - 1 = 36x−1=36

The candidate is 373737. An even index is the one that can add a value, because squaring makes two sides that differed in sign agree. Graph each side and the solutions are where the two graphs meet, so a candidate sitting anywhere else came out of the squaring.

A denominator. First write down the values that make a denominator zero, because the original equation bars them however the working ends. Then multiply every term, on both sides, by the least common denominator.

xx−12=3\frac{x}{x - 12} = 3x−12x​=3 x=3(x−12)x = 3(x - 12)x=3(x−12)

Here that value is 121212. Cross-multiplying is the shortcut for one fraction equal to one fraction, and it does not reach a sum of fractions.

A fractional exponent. In xm/nx^{m/n}xm/n, in lowest terms with mmm and nnn positive, the nnn is a root and the mmm is a power. Raise both sides to nm\frac{n}{m}mn​, then decide which signs the original allows.

x3/5=kx^{3/5} = kx3/5=k x=k5/3x = k^{5/3}x=k5/3

Both mmm and nnn are odd here, so that one candidate is the whole answer. An even nnn or an even mmm can change the count, in either direction.

An absolute value. ∣A∣|A|∣A∣ is the distance from AAA to zero. Set equal to a positive number it gives two equations, equal to zero it gives the single equation A=0A = 0A=0, and equal to a negative number it gives none. From ∣x+1∣=15|x + 1| = 15∣x+1∣=15:

x+1=15x + 1 = 15x+1=15 x+1=−15x + 1 = -15x+1=−15

The solutions are 141414 and −16-16−16.

What the equation hides the variable in What can go wrong
A radical An even index accepts a value the original rejects
A denominator Clearing accepts the value that made it zero
A fractional exponent An even root can accept a value, an even power can hide one
An absolute value One of the two cases can fail

Why the rule exists

Doing the same thing to both sides keeps an equation true, but only some of those moves can be run backward. Squaring cannot: 333 and −3-3−3 have the same square, so squaring throws away the difference between them.

Two sides that disagreed only in sign become equal, and the candidate that appears is real arithmetic on a false statement. An even root index inside a fractional exponent loses the same thing, because undoing it squares.

Clearing a denominator does the same thing another way. Multiplying by x−12x - 12x−12 is multiplying by zero when xxx is 121212, and multiplying by zero makes any two sides agree. That is why the value is barred before the working starts.

An absolute value is not an operation to undo but a description of two possibilities, so splitting it against a positive number loses nothing. Against a right side that holds the variable it does lose something. No absolute value is ever negative, so a case whose right side comes out negative fails.

Worked examples

1. Get the radical alone before squaring

Solve 2x−3−1=6\sqrt{2x - 3} - 1 = 62x−3​−1=6.

Question asks: the value of xxx.

First move: the radical is not alone yet, so add 111 to both sides before squaring anything.

2x−3=7\sqrt{2x - 3} = 72x−3​=7

Now square both sides.

2x−3=492x - 3 = 492x−3=49 2x=522x = 522x=52 x=26x = 26x=26

Answer: 262626

Check: you squared both sides, so put the candidate back into the equation as it was written. Doubling 262626 and subtracting 333 leaves 494949, whose square root is 777, and 777 less 111 is 666.

Common mistake: squaring while the −1-1−1 is still on the left. A square reaches the whole side it lands on, so the radical survives the squaring.

2. Clear a shared denominator, then discard the value it forbids

Solve x2−4xx−9=45x−9\dfrac{x^2 - 4x}{x - 9} = \dfrac{45}{x - 9}x−9x2−4x​=x−945​.

Question asks: the value of xxx.

First move: both sides carry the same denominator, so 999 is forbidden. Write that down, then multiply both sides by x−9x - 9x−9.

x2−4x=45x^2 - 4x = 45x2−4x=45 x2−4x−45=0x^2 - 4x - 45 = 0x2−4x−45=0

Two numbers multiply to −45-45−45 and add to −4-4−4: they are −9-9−9 and 555.

(x−9)(x+5)=0(x - 9)(x + 5) = 0(x−9)(x+5)=0

The two candidates are 999 and −5-5−5.

Answer: −5-5−5

Check: you multiplied by an expression holding the variable, so test both candidates in the equation as it was written. The candidate 999 makes each denominator zero, so the original equation has no value there at all. The candidate −5-5−5 gives 454545 over −14-14−14 on each side.

Common mistake: reporting 999. The algebra produces it, and the equation you were handed bars it.

3. Test both cases when the right side holds the variable

Solve ∣x−10∣=2x+1|x - 10| = 2x + 1∣x−10∣=2x+1.

Question asks: every value of xxx that works.

First move: split the absolute value into its two cases. The right side holds the variable, so it can come out negative, and a case that does is a case that fails.

x−10=2x+1x - 10 = 2x + 1x−10=2x+1 x−10=−2x−1x - 10 = -2x - 1x−10=−2x−1

Take the first case. Subtract xxx from both sides.

−10=x+1-10 = x + 1−10=x+1 x=−11x = -11x=−11

Now the second case. Add 2x2x2x to both sides.

3x−10=−13x - 10 = -13x−10=−1 3x=93x = 93x=9 x=3x = 3x=3

Answer: 333

Check: the absolute value was set equal to an expression holding the variable, so test both candidates. At −11-11−11 the left side comes to 212121 and the right side comes to −21-21−21, so that candidate fails. At 333 both sides come to 777.

Common mistake: reporting both candidates. An absolute value is never negative, so a case whose right side lands below zero cannot hold.

Special cases

Cases where the number of solutions changes

An absolute value is never negative, so ∣3x+2∣=−5|3x + 2| = -5∣3x+2∣=−5 has no solution. Neither case is worth writing.

An even root is never negative either, so x+4=−6\sqrt{x + 4} = -6x+4​=−6 has no solution. Squaring both sides here still produces a candidate, and that candidate fails the original.

A rational equation whose only candidate is a forbidden value has no solution, since nothing else was ever available.

An even root index in xm/nx^{m/n}xm/n bars a negative right side. In x3/2=−8x^{3/2} = -8x3/2=−8 the 222 is a square root, so the base is nonnegative and the left side is too. Nothing solves it, and raising both sides to 23\frac{2}{3}32​ still returns 444.

An even power in xm/nx^{m/n}xm/n gives a second solution, but only against a positive right side. In x2/3=4x^{2/3} = 4x2/3=4 the 333 is a cube root, which accepts a negative base, and the square makes −8-8−8 and 888 agree. Both solve it; raising to 32\frac{3}{2}23​ returns only 888.

The other two right sides give fewer. x2/3=0x^{2/3} = 0x2/3=0 has the single solution 000, and x2/3=−4x^{2/3} = -4x2/3=−4 has none, since an even power is never negative. A stated condition such as x>0x > 0x>0 rules a negative solution out as well.

Common traps

A candidate is not a solution until the original accepts it

The last line of correct algebra is not the answer. Most routes here can hand back a value the original rejects.

Trap Quick check
Reporting every candidate after squaring Put each one back in the equation as it was written
Squaring before the radical stands alone Isolate first, then undo the root
Writing only the positive case of an absolute value Two cases unless the right side is zero or negative
Canceling a denominator and dropping its restriction A canceled factor still forbids its zero
Reading a fractional exponent as a multiplier The exponent is undone by a power, not by a division

The method: Ask, free, undo, check

  1. Name the ask, and name what the equation forbids. The value of the variable, one of two values, a constant, or a count of solutions. Then write down the values that would make a denominator zero, and note whether a radical or an absolute value has to stay nonnegative.
  2. Free the part that hides the variable. Move constants and coefficients away from the radical, the absolute value, or the power until it stands alone. For fractions, multiply every term on both sides by the least common denominator. Cross-multiply only when one fraction equals one fraction, or cancel a factor the numerator and the denominator share.
  3. Undo what is left. Raise an isolated radical to its index, a fractional power to its reciprocal, or split an absolute value into its cases. An even numerator with a positive right side means the opposite of the base you found also solves it. A cleared equation is linear or quadratic, so finish it the usual way.
  4. Check, then answer the ask. Squaring both sides can add a candidate, and so can a variable expression multiplied in or canceled. So can an absolute value set equal to a variable expression, or xm/nx^{m/n}xm/n with an even root index. After any of them, test each candidate in the equation you were given and drop the ones that fail.

Graph each side to see which candidates are real

A graphing calculator is built into the testing app and is allowed on every Math question.

Enter the left side as one function and the right side as another, then look at where the two graphs meet. Those intersections are the solutions, so a candidate your algebra produced that no intersection sits on is one the original equation rejects.

A window can hide an intersection, so settle a candidate in the original equation. By hand is faster when the radical or the absolute value already stands alone.

Practice

Work each item with the method, under a rough clock: about a minute for a bare equation, and up to about two minutes once there is a context to translate or a graph or table to read first. What is the lesser of the two values of xxx that satisfy the equation below?

∣2x−8∣=20|2x - 8| = 20∣2x−8∣=20
Correct. The negative case leaves 2x=−122x = -122x=−12, so the lesser solution is −6-6−6.

The method, applied

Step 1. The ask is the lesser of two values. There is no denominator and no radical here, so nothing is forbidden.

Step 2. The absolute value stands alone, so the split is the first move.

Step 3. Write the two cases, one for each direction.

2x−8=202x - 8 = 202x−8=20 2x=282x = 282x=28 x=14x = 14x=14

Now the case that sets the inside equal to the negative.

2x−8=−202x - 8 = -202x−8=−20 2x=−122x = -122x=−12 x=−6x = -6x=−6

Step 4. The right side is a positive number, so both cases hold. The lesser of the two solutions is −6-6−6.

What is the value of xxx in the equation below?

6x+2=5\frac{6}{x} + 2 = 5x6​+2=5
Correct. Freeing the fraction leaves 6=3x6 = 3x6=3x, so xxx is 222.

The method, applied

Step 1. The ask is the value of xxx. The denominator is xxx, so 000 is forbidden.

Step 2. The fraction is not alone, so free it first. Subtract 222 from both sides.

6x=3\frac{6}{x} = 3x6​=3

Now multiply both sides by xxx.

6=3x6 = 3x6=3x

Step 3. Nothing is left to undo but the coefficient, so divide both sides by 333.

x=2x = 2x=2

Step 4. You multiplied by an expression holding the variable, so put the candidate back. It is not 000, and 666 divided by 222 is 333, which added to 222 gives 555. The value of xxx is 222.

What is the value of xxx in the equation below?

5x−2=3x+4\frac{5}{x - 2} = \frac{3}{x + 4}x−25​=x+43​
Correct. Cross-multiplying and collecting leaves 2x=−262x = -262x=−26, so xxx is −13-13−13.

The method, applied

Step 1. The ask is the value of xxx. The two denominators are zero at 222 and at −4-4−4, so those values are barred whatever the working gives.

Step 2. One fraction equals one fraction, so cross-multiply.

5(x+4)=3(x−2)5(x + 4) = 3(x - 2)5(x+4)=3(x−2)

Step 3. Distribute on both sides, keeping the minus with the 222.

5x+20=3x−65x + 20 = 3x - 65x+20=3x−6 2x=−262x = -262x=−26 x=−13x = -13x=−13

Step 4. You multiplied by expressions holding the variable, so check the candidate. It is neither 222 nor −4-4−4, and each side of the original comes to −13\frac{-1}{3}3−1​. The value of xxx is −13-13−13.

What is the value of xxx in the equation below?

(x−3)3/2=8(x - 3)^{3/2} = 8(x−3)3/2=8
Correct. Raising both sides to the power 23\frac{2}{3}32​ leaves x−3=4x - 3 = 4x−3=4, so xxx is 777.

The method, applied

Step 1. The ask is the value of xxx. The 222 under the exponent is a square root, so the base cannot be negative.

Step 2. The power stands alone, and the right side 888 is positive, which an even root allows.

Step 3. Undo the exponent by raising both sides to its reciprocal, 23\frac{2}{3}32​. The cube root of 888 is 222, and 222 squared is 444.

x−3=4x - 3 = 4x−3=4 x=7x = 7x=7

Step 4. The root index is even, so put the candidate back. At 777 the base x−3x - 3x−3 is 444, which is nonnegative, and 43/24^{3/2}43/2 is 888. The exponent's numerator is odd, so no second solution was dropped. The value of xxx is 777.

For a certain pendulum, the time ttt, in seconds, of one full swing is modeled by the equation below, where LLL is the pendulum's length in inches.

t=L12t = \sqrt{\frac{L}{12}}t=12L​​

The method, applied

Step 1. The ask is a length in inches. A square root is never negative, and the time given is positive, so nothing is ruled out.

Step 2. Put 222 in place of ttt. The radical already stands alone.

2=L122 = \sqrt{\frac{L}{12}}2=12L​​

4=L124 = \frac{L}{12}4=12L​ L=48L = 48L=48

What is the solution to the equation below?

x+3=x−3\sqrt{x + 3} = x - 3x+3​=x−3
Correct. Squaring and factoring gives the candidates 666 and 111, and only 666 satisfies the original equation.

The method, applied

Step 1. The ask is the value of xxx. The radicand x+3x + 3x+3 cannot be negative, and a square root is never negative either, so the right side x−3x - 3x−3 cannot be negative and xxx is at least 333.

Step 2. The radical stands alone on the left, so the square is the first move rather than the second.

Step 3. Square both sides. The right side is a binomial, so its square carries a middle term.

x+3=x2−6x+9x + 3 = x^2 - 6x + 9x+3=x2−6x+9 x2−7x+6=0x^2 - 7x + 6 = 0x2−7x+6=0 (x−6)(x−1)=0(x - 6)(x - 1) = 0(x−6)(x−1)=0

The two candidates are 666 and 111.

Step 4. You squared both sides, so test both candidates in the equation as it was written. At 666 the left side comes to 333 and so does the right side. At 111 the left side comes to 222 and the right side comes to −2-2−2, so that candidate fails. The solution is 666.

Practice 7

  • Advanced

In the equation below, kkk is a constant. For what value of kkk does the equation have no solution?

x+kx−7=2\frac{x + k}{x - 7} = 2x−7x+k​=2
Correct. The one candidate is k+14k + 14k+14, which fails only when it is the forbidden 777, so kkk is −7-7−7.

The method, applied

Step 1. The ask is the constant kkk, not a value of xxx. The denominator is zero at 777, so 777 is the one value xxx may not take.

Step 2. Multiply both sides by x−7x - 7x−7.

x+k=2(x−7)x + k = 2(x - 7)x+k=2(x−7)

Step 3. Distribute across the grouping, then collect.

x+k=2x−14x + k = 2x - 14x+k=2x−14 k+14=xk + 14 = xk+14=x

The equation has exactly one candidate, and it is k+14k + 14k+14. It can fail only by being the forbidden value.

k+14=7k + 14 = 7k+14=7 k=−7k = -7k=−7

Step 4. You multiplied by an expression holding the variable, so test the candidate. With kkk at −7-7−7 the candidate is 777, which makes the denominator zero, so nothing satisfies the equation. The value of kkk is −7-7−7.
