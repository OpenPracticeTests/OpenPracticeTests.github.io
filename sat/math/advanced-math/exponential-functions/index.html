Exponential Functions

  • Advanced Math
  • Nonlinear functions
←PreviousAll Math lessonsNext→

An exponential function multiplies the output by the same factor for every step the input takes. Decide first what the question wants: the starting value, the factor, the percent behind that factor, or a value the model gives.

Key takeaways

  • An exponential function is f(x)=a⋅bxf(x) = a \cdot b^xf(x)=a⋅bx, where aaa is the output at an input of zero.
  • The base bbb is the factor: one step of the input multiplies the output by it.
  • With a positive starting value, a base above 111 grows and a base between 000 and 111 decays.
  • A base of 1.071.071.07 is a 777 percent rise; a base of 0.850.850.85 is a 151515 percent fall.
  • Over equal steps of the input, a constant positive ratio is exponential and a constant difference is linear.
  • When one factor covers kkk units of the input, the exponent is xk\frac{x}{k}kx​.
  • Outputs nnn steps apart give bnb^nbn, so the base is the nnnth root of their ratio.

What the SAT may ask

  • Write the function that models a stated percent rise or fall.
  • Find the starting value or the factor from a table or from one later output.
  • Find the value a model gives at a stated input.
  • Decide whether a table is linear or exponential.
  • Rewrite an exponential function with a different base.
  • Solve for the exponent when the output is given.

The rule

An exponential function is written f(x)=a⋅bxf(x) = a \cdot b^xf(x)=a⋅bx, with the base bbb positive. The number aaa is the starting value, the output when the input is zero, because b0b^0b0 is 111. The base is a factor: every step of one in the input multiplies the output by it.

With a positive starting value, a base above 111 grows and a base between 000 and 111 decays. A base of exactly 111 leaves every output equal to aaa.

The percent is hidden in the base. Write the base as 1+r1 + r1+r for a rise and 1−r1 - r1−r for a fall, where rrr is the percent written as a decimal. So a rise of 303030 percent makes the base 1.301.301.30, not 0.300.300.30, and a fall of 303030 percent makes it 0.700.700.70, the share that is kept.

When one factor covers more than one unit of the input, the exponent carries a division. A quantity that doubles every 333 years is

f(t)=a⋅2t/3f(t) = a \cdot 2^{t/3}f(t)=a⋅2t/3

because ttt years hold t3\frac{t}{3}3t​ doublings. The stated factor is not the factor for one unit: one year multiplies by 21/32^{1/3}21/3, about 1.261.261.26, and not by 222.

A table is exponential when outputs at equally spaced inputs share a constant positive ratio. Check the inputs first. Where they step by one, divide each output by the one before it, and equal positive ratios mean exponential while equal differences mean linear. Where they step by nnn, the ratio is bnb^nbn rather than bbb.

Why the rule exists

Adding the same amount every step moves the output the same distance every time, which draws a straight line. Multiplying by the same factor moves it by an amount proportional to the output itself, which is why the graph bends.

The percent hides in the base for the same reason. Adding 777 percent to a quantity leaves the whole quantity plus 0.070.070.07 of it, and that is 1.071.071.07 times it. One multiplication does both jobs at once, so a model can apply it again and again.

Worked examples

1. Turn a stated percent fall into a base

A charity's monthly donations fall by 121212 percent each month after its appeal ends. In the month the appeal ends, donations are 5,0005{,}0005,000 dollars. Write a function DDD giving the donations mmm months later, and say what each number in it means.

Question asks: the model, and the meaning of its two numbers.

First move: turn the percent into a base. A fall of 121212 percent leaves 888888 percent of the month before it.

b=1−0.12b = 1 - 0.12b=1−0.12 b=0.88b = 0.88b=0.88

Donations are 5,0005{,}0005,000 dollars when mmm is zero, so that is the starting value.

D(m)=5000(0.88)mD(m) = 5000(0.88)^mD(m)=5000(0.88)m

Answer: D(m)=5000(0.88)mD(m) = 5000(0.88)^mD(m)=5000(0.88)m

The 5,0005{,}0005,000 is in dollars, the donations in the month the appeal ends. The 0.880.880.88 has no units: it is the share of one month's donations that the next month keeps.

Check: you computed the base from a percent, so run one month. Multiplying 500050005000 by 0.880.880.88 gives 440044004400, a drop of 600600600, and 121212 percent of 500050005000 is 600600600.

Common mistake: writing 5000(0.12)m5000(0.12)^m5000(0.12)m uses the share lost where the share kept belongs, which strips away 888888 percent in a month instead of 121212.

2. Read a model whose factor covers several months

A company's stored data, in gigabytes, is modeled by N(t)=500⋅3t/4N(t) = 500 \cdot 3^{t/4}N(t)=500⋅3t/4, where ttt is the number of months since the store opened. How much data is stored after 121212 months, and what does the 444 mean?

Question asks: a value at a stated input, and the meaning of the 444.

First move: work out the exponent before touching the power.

124=3\frac{12}{4} = 3412​=3

Twelve months hold three of the periods this model counts.

N(12)=500⋅33N(12) = 500 \cdot 3^{3}N(12)=500⋅33 N(12)=13500N(12) = 13500N(12)=13500

Answer: 13,50013{,}50013,500 gigabytes

The 444 is the number of months one tripling takes. Every 444 months the stored data is multiplied by 333.

Common mistake: using 121212 as the exponent counts twelve triplings rather than three, because it reads each month as a whole period.

3. Tell an exponential table from a linear one

The tables give values of two functions, ggg and hhh. Which one could be exponential?

x g(x)
0 12
1 36
2 60
3 84
x h(x)
0 12
1 36
2 108
3 324

Question asks: which table multiplies by a constant factor.

First move: the two tables agree on their first two rows, so the third row is what decides it. Divide each output by the one before it.

For ggg:

3612=3\frac{36}{12} = 31236​=3 6036=53\frac{60}{36} = \frac{5}{3}3660​=35​

The two ratios differ, so no single factor describes ggg. Its differences are 242424 every time, which makes it linear.

For hhh:

10836=3\frac{108}{36} = 336108​=3 324108=3\frac{324}{108} = 3108324​=3

Answer: the table for hhh.

Check: you computed a ratio, so test it on the row you did not use. The first row of hhh is 121212, and multiplying it by 333 gives the 363636 the table prints next.

Common mistake: stopping at the first two rows. Two points fit a linear function and an exponential one alike, so the third row is the first place they can part.

Special cases

A base of one, a decay with no floor, and a shifted exponent

With a starting value that is not zero, a base of exactly 111 is the one case that is both. Every output equals aaa, so the graph is a horizontal line, which a linear rule describes just as well.

With a positive starting value and a positive base, an exponential function never reaches zero, because a decaying quantity keeps a share of itself at every step. The formula has a value at every input, and a real quantity stops following it at some point, so use the domain the question states.

Something added to or taken from the exponent moves the starting value. In N(t)=200⋅2t−3N(t) = 200 \cdot 2^{t - 3}N(t)=200⋅2t−3 the 200200200 is the output at an input of 333, not at 000. At 000 the output is 200⋅2−3200 \cdot 2^{-3}200⋅2−3, which is 252525.

Read aaa as the output at zero when the exponent comes to zero there. A divided exponent like t4\frac{t}{4}4t​ does; a shifted one like t−3t - 3t−3 does not.

Equal differences over equal input steps mean linear rather than growth or decay. The rate of change, the starting value read as an intercept, and the constant-difference test belong to Linear Functions.

Common traps

The percent, the factor, and the coefficient

A base is a multiplier, not the percent change. It says what share of the old amount the new one is, so read the percent out of it.

Trap Quick check
Using a stated percent as the base A rise of 303030 percent is a base of 1.301.301.30
Reading a base of 0.850.850.85 as an 858585 percent fall Subtract the base from 111 to get the fall
Folding the coefficient into the base Only bbb carries the exponent, so a⋅bxa \cdot b^xa⋅bx is not (ab)x(ab)^x(ab)x
Using a ratio taken across several steps as the factor Take the nnnth root when the two outputs are nnn steps apart
Stepping a table on by adding its last difference Over equal input steps its differences are multiplied by the same factor its outputs are

The method: Ask, find, build, answer

  1. Name the ask. The starting value, the base, the percent behind it, a value at a stated input, the input that reaches a stated output, or the model itself. Write down which one before you touch the numbers.
  2. Find aaa and bbb. In an equation already written a⋅bxa \cdot b^xa⋅bx, aaa stands alone and bbb carries the exponent. In a table, divide consecutive outputs: equal ratios mean exponential, and a step of one then gives bbb while a step of nnn gives bnb^nbn. A stated rise of rrr gives 1+r1 + r1+r and a fall gives 1−r1 - r1−r.
  3. Build or use f(x)=a⋅bxf(x) = a \cdot b^xf(x)=a⋅bx. Substitute an input to get an output. Divide a later output by bbb raised to its input to get back to aaa. To change the base, write the old one as a power of the new one. To find an exponent, get the power alone and write both sides over one base.
  4. Answer the ask, and test what you built. A base you computed, a model you assembled or rewrote, and a value you solved for all go back into the question. Only a model handed to you whole and used once forwards has nothing to test. Then give the quantity the ask names, with its units when the question has any.

Let a table do the repeated multiplication

A graphing calculator is built into the testing app and is allowed on every Math question.

Enter the function and read its table of values. Stepping the input by one shows the factor for one step directly, since each output is the one before it times that factor.

When the two sides will not go over one base, graph the model against the target value as a horizontal line. Read the input at their intersection.

By hand is faster when the model is already written and one substitution answers the question.

Practice

Work each item with the method, under a rough clock: about a minute for a bare equation, and up to about two minutes once there is a context to translate or a graph or table to read first. The Math section gives you about 95 seconds a question on average, so that range is test-day pace rather than a drill speed. Press Show solution to see the steps, one to a line.

A podcast has 400400400 subscribers, and the number of subscribers grows by 252525 percent each month. How many subscribers will the podcast have 222 months from now?

Correct. The factor is 1.251.251.25, and 400(1.25)2400(1.25)^2400(1.25)2 is 625625625.

The method, applied

Step 1. The ask is a value at a stated input, two months from now.

Step 2. The rate is given as a percent, so the base is 111 plus that percent as a decimal. The starting value is the 400400400 subscribers there are now.

b=1+0.25b = 1 + 0.25b=1+0.25 b=1.25b = 1.25b=1.25

Step 3. Substitute an input of 222.

f(2)=400(1.25)2f(2) = 400(1.25)^2f(2)=400(1.25)2 f(2)=400(1.5625)f(2) = 400(1.5625)f(2)=400(1.5625) f(2)=625f(2) = 625f(2)=625

Step 4. You computed the base from a percent, so run one month first. Multiplying 400400400 by 1.251.251.25 gives 500500500, a rise of 100100100, and 252525 percent of 400400400 is 100100100. The answer is 625625625 subscribers.

Practice 3

  • Advanced Math

  • Standard

A radio beacon's transmitting power falls to half its value every 555 days. When the beacon is switched on it transmits at 480480480 watts. Which function gives the transmitting power, in watts, ddd days after the beacon is switched on?

Correct. The power keeps half of itself every five days, so the exponent is the number of days divided by 555.

The method, applied

Step 1. The ask is the model itself, so nothing is evaluated.

Step 2. The base comes straight from the word half, and the starting value is the 480480480 watts at zero days. One halving covers 555 days rather than one, so the exponent is the number of days divided by 555.

Step 3. Put the three parts together.

P(d)=480(12)d/5P(d) = 480\left(\frac{1}{2}\right)^{d/5}P(d)=480(21​)d/5

Step 4. Read the model back at five days: the exponent comes to 111, so the power halves to 240240240 watts, which is what the wording describes. The model that halves once every five days puts ddd over 555 in the exponent.

If 3⋅3x=2433 \cdot 3^x = 2433⋅3x=243, what is the value of xxx?

Correct. Dividing by 333 leaves 3x=813^x = 813x=81, which is 343^434, so xxx is 444.

The method, applied

Step 1. The ask is the exponent, which is the input rather than an output.

Step 2. The base 333 is handed over and so is the coefficient, which is also 333. Divide the coefficient out before touching the power.

3x=813^x = 813x=81

Step 3. Write 818181 as a power of the same base, then match the exponents.

81=3481 = 3^481=34 x=4x = 4x=4

Step 4. Put 444 back: 343^434 is 818181, and 333 times 818181 is the 243243243 the equation prints. The value of xxx is 444.
