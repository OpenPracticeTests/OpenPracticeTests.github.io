One-Variable Data: Center and Spread

  • Problem-Solving and Data Analysis
  • One-variable data: distributions and measures of center and spread
←PreviousAll Math lessonsNext→

One-variable data is a single list of numbers, described by where its center sits and how far its values reach. Decide first which measure the question wants, because each measure answers a different question.

Key takeaways

  • The mean is the total of the values divided by how many there are.
  • The median is the middle value in order, or the average of the middle two when the count is even.
  • A frequency column says how often a value appears, so the count is its total.
  • One far-out value pulls the mean toward it, and usually moves the median much less.
  • Adding the same number to every value shifts the center by that number and leaves the spread alone.
  • The interquartile range is the third quartile minus the first, and a box plot draws it as the box.

What the SAT may ask

  • Find the mean, the median, the mode, the range, or the interquartile range of a data set.
  • Read a data set off a frequency table, a dot plot, a histogram, or a box plot.
  • Decide which of two data sets has the greater standard deviation.
  • Say how the mean and the median change when one value changes.
  • Find a missing value from a stated mean or a stated median.
  • Find the mean or the median of two groups combined.

The rule

A data set is a list of numbers, and five measures describe it.

The mean is the total divided by the count.

mean=sum of the valueshow many values\text{mean} = \frac{\text{sum of the values}}{\text{how many values}}mean=how many valuessum of the values​

The median is the middle value once the values are in order. With an even count it is the average of the two middle values, and need not be a value in the set. The mode is the value that appears most often. The range is the greatest value minus the least.

For the set 777, 101010, 161616, 222222:

mean=554=13.75\text{mean} = \frac{55}{4} = 13.75mean=455​=13.75 median=10+162=13\text{median} = \frac{10 + 16}{2} = 13median=210+16​=13 range=22−7=15\text{range} = 22 - 7 = 15range=22−7=15

The standard deviation measures how far the values sit from their own mean, built from the squared distances rather than a plain average of them. Values bunched near the mean give a small one, and values reaching far from it give a large one. This page compares two sets rather than computing it.

A frequency table lists each value once and says how many times it appears. The count is the frequency column's total, and the total of the values is each value times its own frequency.

One value far from the rest pulls the mean toward it, and usually moves the median much less.

In a set of three or more, replacing the greatest with a larger one leaves the median where it was: no position changed. Adding a value changes the count, so it can move the median. 111, 222, 333 has median 222; 111, 222, 333, 100100100 has median 2.52.52.5.

Add the same number to every value, or multiply every value by the same number, and the centers follow; only the multiplying changes the spread.

Why the rule exists

The mean shares the total out equally, so changing one value by 121212 moves the total by 121212 and the mean by 121212 divided by the count.

The median is about position: which value sits in the middle once the values are in order. In a set of three or more, how large the largest value is plays no part in it.

Spread depends on the gaps between values, not on where those values sit. Slide the whole set along the number line and every gap is what it was, which is why a shift leaves the range and the standard deviation alone. Stretch the set and every gap stretches with it.

Worked examples

1. Find the median from a frequency table

The table shows how long each of the calls to a help desk lasted, in whole minutes. What is the median call length?

Minutes Number of calls
3 4
5 8
8 6
11 4
14 2

Question asks: the median of the call lengths.

First move: the count is the frequency column's total, so add that column first.

4+8+6+4+2=244 + 8 + 6 + 4 + 2 = 244+8+6+4+2=24

Twenty-four is even, so the median averages the twelfth and thirteenth values.

Cumulate the frequencies. The 333-minute calls fill positions one through four, the 555-minute calls positions five through twelve, and the 888-minute calls positions thirteen through eighteen. So the twelfth value is 555 and the thirteenth is 888.

5+82=6.5\frac{5 + 8}{2} = 6.525+8​=6.5

Answer: 6.56.56.5 minutes

Check: a center was worked out, so it must land between the least value and the greatest. It sits between 333 and 141414.

Common mistake: taking the middle row, 888 minutes, as the median. That reads the value column as the data set and ignores the frequencies.

2. Decide which data set has the greater standard deviation

Data set A consists of the values 212121, 222222, 232323, 242424, and 252525, and data set B of 131313, 181818, 232323, 282828, and 333333. Both have a mean of 232323. Which data set has the greater standard deviation?

Question asks: which of two sets is more spread out.

First move: the two means are equal and are handed over, so compare how far each set's values sit from 232323.

A's farthest value is two away.

25−23=225 - 23 = 225−23=2

B's farthest value is ten away.

33−23=1033 - 23 = 1033−23=10

Every value of B sits farther from the mean than A's, except the middle one, where the two tie.

Answer: data set B

The answer is a spread, so no check applies.

Note: the two ends alone are not enough. The sets 000, 000, 101010, 101010 and 000, 555, 555, 101010 share a range. The first has the larger standard deviation, because none of its values sits near the mean.

Common mistake: reading two equal means as equal spread. A mean says where the middle of a set sits and says nothing about how far its values reach.

3. Move the greatest value and watch the two centers

A data set consists of the seven values 444, 666, 777, 999, 101010, 121212, and 151515. The value 151515 is replaced by 505050. What happens to the mean and to the median?

Question asks: the direction each of the two centers moves.

First move: work out both centers before the change.

mean=637=9\text{mean} = \frac{63}{7} = 9mean=763​=9

The values are already in order, so the median is the fourth, which is 999.

Now replace the largest value and take the mean again.

mean=987=14\text{mean} = \frac{98}{7} = 14mean=798​=14

The list is still in order and still has seven values, so the fourth is still 999.

Answer: the mean rises from 999 to 141414, and the median stays at 999

Check: a center was worked out, so it must land between the least value and the greatest. The new mean sits between 444 and 505050.

Common mistake: expecting the median to move because the largest value moved. Replacing the largest with a larger one leaves every position where it was.

Special cases

Sets with no mode, and what a histogram or a box plot shows

A data set can have two modes, or none. No value repeating means no mode, and two values tied for the most appearances means two.

A histogram keeps the intervals and throws the values away, so it gives no exact center, and does not generally settle which bar holds the mean. Do not stand a bar's midpoint in for the values it holds, and read the tallest bar as the most common interval rather than the mode.

Add the bar heights from the left to reach the middle position. On an odd count that bar holds the median. On an even count the two middle positions can sit in different bars, and the median is then between them.

A box plot marks the two whisker ends and the three quartiles between them. The line inside the box is the median, and the box spans the first quartile to the third. Its width is the interquartile range.

IQR=Q3−Q1\text{IQR} = Q_3 - Q_1IQR=Q3​−Q1​

A whisker end is not always the least or greatest value. Many plots draw far-out values as separate points and stop the whiskers short, so read those marks before calling the whisker span a range. The five numbers do not generally determine the mean.

Common traps

The measure that was not asked for

One list answers five different questions, so the wrong measure is always available and always looks finished.

Trap Quick check
Reporting the mean where the median was asked Name the measure before you compute
Calling a box plot's whisker span the range Look for outliers marked outside the whiskers
Taking the middle of the list as it is written Put the values in order first
Reading a frequency as a data value The frequency column counts, it does not measure
Averaging a table's value column and ignoring the frequencies Multiply each value by its own frequency first
Averaging two groups' means when the groups are different sizes Add the totals, then divide by the total count

The method: Name the measure, order, work, check

  1. Name the measure the question asks for. Mean, median, mode, range, standard deviation, or a comparison between two of them. Write it down before any arithmetic.
  2. Put the values in order and count them. Only the median needs the order, but it also shows the least, the greatest and any repeat. In a frequency table or a display, the count is the frequency total.
  3. Carry out the one move the measure names. Add and divide for the mean, take the middle for the median, subtract the ends for a range. Compare a standard deviation rather than computing one: the more bunched set has the smaller one, and a shift leaves it alone.
  4. Check a center you worked out, then answer the ask. A mean or a median must land between the least and the greatest of the numbers it came from. Those are the list's own values, or two group means. Skip the check when the answer is a spread, or when a center was handed over rather than found.

Order the values first

A graphing calculator is built into the testing app and is allowed on every Math question.

Put the list in order before you touch the calculator. A mean of five or six numbers is then one addition and one division.

Reach for it when a frequency table has many rows and the products are awkward.

The box plot summarizes a data set. What is the interquartile range of the data set?

Correct. The box runs from 212121 to 444444, so the interquartile range is 232323.

The method, applied

Step 1. The measure named is the interquartile range, which is a spread.

Step 2. A box plot arrives in order already, so nothing has to be sorted. Read the two edges of the box: the first quartile is 212121 and the third is 444444.

Step 3. Subtract the first quartile from the third.

44−21=2344 - 21 = 2344−21=23

Step 4. The answer is a spread, so no check applies. The interquartile range is 232323.

The frequency table shows the 202020 values in a data set. What is the mean of the data set?

Value Frequency
4 4

Correct. The values total 158158158 over a count of 202020, which is a mean of 7.97.97.9.

The method, applied

Step 1. The measure named is the mean.

Step 2. The count is the total of the frequency column, which is 202020, and not the four rows of the table.

Step 3. Multiply each value by its own frequency and add the products.

4(4)+6(5)+8(5)+12(6)=1584(4) + 6(5) + 8(5) + 12(6) = 1584(4)+6(5)+8(5)+12(6)=158

15820=7.9\frac{158}{20} = 7.920158​=7.9

A data set consists of the six values 141414, 999, 232323, 666, 111111, and 999. How much greater is the mean of the data set than the median?

Correct. The mean is 121212 and the median is 101010, so the mean is greater by 222.

The method, applied

Step 1. The ask names two measures, the mean and the median, and wants the distance between them.

Step 2. Put the values in order: 666, 999, 999, 111111, 141414, 232323. There are six, so the median is the average of the third and fourth.

Step 3. Take the mean first.

mean=726=12\text{mean} = \frac{72}{6} = 12mean=672​=12

Then the median.

median=9+112=10\text{median} = \frac{9 + 11}{2} = 10median=29+11​=10

Subtract to get the gap.

12−10=212 - 10 = 212−10=2

Step 4. Two centers were worked out, and both land between 666 and 232323. The mean is greater by 222.

The six values 111111, 151515, 181818, xxx, 262626, and 313131 are listed in increasing order. The median of the data set is 212121. What is the value of xxx?

Correct. The two middle values total 424242, and taking 181818 away leaves xxx as 242424.

The method, applied

Step 1. The measure is the median, and the question hands it over. The ask is one entry of the list.

Step 2. The values are already in increasing order and there are six of them, so the median is the average of the third and fourth, which are 181818 and xxx.

Step 3. Write that average as the stated median.

18+x2=21\frac{18 + x}{2} = 21218+x​=21

Multiply both sides by two.

18+x=4218 + x = 4218+x=42

Subtract 181818 from both sides.

x=24x = 24x=24

That value has to keep the list in the increasing order the stem states, and 242424 does sit between 181818 and 262626, so it really is the fourth entry.

Step 4. The median was handed over rather than found, so no check applies. The value of xxx is 242424.

A courier collected 151515 small parcels with a mean mass of 242424 ounces and 555 large parcels with a mean mass of 444444 ounces. What is the mean mass of all 202020 parcels?

Correct. The two groups total 580580580 ounces over 202020 parcels, which is a mean mass of 292929 ounces.

The method, applied

Step 1. The measure named is the mean, over all twenty parcels.

Step 2. The count is 202020. No individual masses are listed, so each group's total has to be built from its own size and its own mean.

Step 3. Take the small parcels' total first.

15×24=36015 \times 24 = 36015×24=360

Now the large parcels' total.

5×44=2205 \times 44 = 2205×44=220

Add the two totals and divide by the count.

360+22020=29\frac{360 + 220}{20} = 2920360+220​=29

Step 4. A center was worked out, so it has to land between the least and the greatest of the numbers it was built from. It sits between the two group means, 242424 and 444444, and nearer the one carrying more parcels. The mean mass is 292929 ounces.

Practice 6

  • Problem-Solving and Data Analysis
  • One-variable data: distributions and measures of center and spread
  • Advanced

A data set has a mean of 343434 and a standard deviation of 777. Each value in the data set is increased by 888. What is the standard deviation of the new data set?

Correct. A shift moves every value the same way, so the distances the standard deviation is built from are unchanged and it is still 777.

The method, applied

Step 1. The measure named is the standard deviation, which is a spread.

Step 2. No values are listed, so there is nothing to order. What the question gives instead is that every value moved by the same amount.

Step 3. The mean moves with the values.

34+8=4234 + 8 = 4234+8=42

A value that sat 777 above the old mean now sits 777 above the new one, because the value and the mean both rose by 888. Every distance behind the standard deviation is what it was.

Step 4. The answer is a spread, so no check applies. The standard deviation is still 777.

Data set A consists of the values 444, 777, 999, and 121212. Data set B consists of the values 555, 888, 111111, 151515, and 212121. What is the median of the data set formed by combining A and B?

Correct. The nine combined values put 999 in the fifth position, which is the middle one.

The method, applied

Step 1. The measure named is the median, of the single data set the two lists form together.

Step 2. Put all nine values into one ordered list: 444, 555, 777, 888, 999, 111111, 121212, 151515, 212121. Nine is odd, so the median is the fifth of them.

Step 3. Count five places in from the left.

median=9\text{median} = 9median=9

Step 4. A center was worked out, so it has to land between the least and the greatest of the numbers it was built from. It sits between 444 and 212121. The median is 999.

A data set consists of the six values 888, 333333, xxx, 252525, 363636, and 303030. The mean of the data set is 262626. What is the median of the data set?

Correct. The missing entry is 242424, so the two middle values in order are 252525 and 303030 and the median is 27.527.527.5.

The method, applied

Step 1. The measure asked for is the median. The list carries an unknown entry, and the stated mean is what recovers it.

Step 2. There are six values, so the mean and the count give the total.

6×26=1566 \times 26 = 1566×26=156

The five known values total 132132132, so subtract to find the missing one.

156−132=24156 - 132 = 24156−132=24

Now the ordered list reads 888, 242424, 252525, 303030, 333333, 363636.

Step 3. Six is even, so average the third and fourth values.

25+302=27.5\frac{25 + 30}{2} = 27.5225+30​=27.5

Step 4. A center was worked out, so it has to land between the least value and the greatest. It sits between 888 and 363636. The median is 27.527.527.5.
